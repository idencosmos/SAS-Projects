# SAS-Projects

> ⚠️ **아카이브 저장소 (Archive Repository)**
>
> 이 저장소의 코드들은 **2017-2019년**에 작성되었으며, 현재는 **참고용으로만 보존**되고 있습니다.
>

## 공통 코드 패턴

대부분의 프로젝트는 다음 3단계 파이프라인을 따릅니다:

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│ Extraction  │ ──▶ │ Preparation │ ──▶ │ Statistics  │
│ (데이터 수집)│     │ (전처리)     │     │ (분석)      │
└─────────────┘     └─────────────┘     └─────────────┘
```

| 단계 | 파일명 패턴 | 역할 |
|------|-----------|------|
| **Extraction** | `Extraction_*.sas`, `ext*.sas` | API 호출, Excel/CSV 읽기, 원본 데이터 수집 |
| **Preparation** | `Preparation_*.sas`, `pre*.sas` | 데이터 정제, 변수 생성, 병합 |
| **Statistics** | `Statistics_*.sas`, `stat*.sas` | 기초통계, 회귀분석, 시각화 |

- **SAS 9.4** (TS1M5, 유니코드 지원)
- SAS/STAT 14.3
- SAS/ETS 14.3
- SAS/GRAPH

### 데이터 형식
- **입력**: Excel (.xlsx), CSV, API (XML/JSON)
- **처리**: SAS 데이터셋 (.sas7bdat)
- **출력**: 통계 결과, 그래프, 보고서

## 실행 가이드

### 기본 설정

1. **작업 디렉토리 설정**: 각 프로젝트 폴더의 SAS 파일에서 `libname` 경로를 본인 환경에 맞게 수정

```sas
/* 예시: 경로 수정 필요 */
libname mylib "C:\Users\사용자\SAS-Projects\0001";
```

2. **실행 순서**: 각 프로젝트 README의 "코드 구조" 섹션 참조

3. **인코딩 주의**: API 데이터 처리 시 SAS 유니코드 버전 권장

### 주의사항

- `(폐기)` 표시된 파일은 개발 과정의 기록용이며 실행 불필요
- `modify` 표시된 파일은 논문 심사 후 수정된 버전
- 대용량 데이터셋은 `.gitignore`로 제외되어 있을 수 있음

## 개요

국토교통부와 통계청 데이터를 활용하여 **주거 실태**와 **주택 정책**을 분석하는 프로젝트입니다.

### 분석 주제

1. **주거 안정성**: 자가점유율, 자가보유율, 점유형태 변화
2. **주거비 부담**: PIR(소득대비 주택가격), RIR(소득대비 임대료)
3. **주택 시장**: 주택보급률, 매매가격지수, 건설 인허가

### 분석 기간

- 주거실태조사: 2006년 ~ 2017년
- 주택보급률: 1995년 ~ 2016년
- 매매가격지수: 1986년 ~ 2012년

## 주요 지표

### 주거 안정성 지표

| 지표 | 설명 |
|-----|------|
| **자가점유율** | 자가에 거주하는 가구 비율 |
| **자가보유율** | 주택을 보유한 가구 비율 |
| **점유형태** | 자가, 전세, 보증금있는월세, 보증금없는월세, 무상 등 |

### 주거비 부담 지표

| 지표 | 설명 | 계산식 |
|-----|------|-------|
| **PIR** | Price Income Ratio | 연소득 대비 주택구입가격 배수 |
| **RIR** | Rent Income Ratio | 월소득 중 월임대료 비율 |
| **LTV** | Loan to Value | 주택가격 대비 대출금 비율 |

### 분류 기준

| 구분 | 분류 |
|-----|------|
| **지역** | 수도권 (서울, 인천, 경기), 지방광역시, 도지역 |
| **소득계층** | 저소득층, 중소득층, 고소득층 |

## 분석 내용

### 시각화 항목

1. **지역별 자가점유율 추이** (2006-2017)
2. **소득계층별 자가점유율 추이**
3. **지역별 자가보유율 추이**
4. **소득계층별 자가보유율 추이**
5. **점유형태별 비율 변화**

### 주요 발견

- 자가점유율: 2017년 전국 57.7% (수도권 49.7%, 도지역 68.1%)
- PIR: 2017년 전국 5.6배 (수도권 6.7배)
- RIR: 2017년 전국 17.0% (수도권 18.4%)
- 월세가구 비중: 2017년 60.4% (임차가구 중)

## 참고

### 데이터 출처

- 국토교통부 통계누리: https://stat.molit.go.kr
- 통계청 KOSIS: https://kosis.kr
- 주거실태조사: 국토교통부 주거복지포털

### 관련 개념

- **주택보급률**: 주택수 / 가구수 × 100
- **(신)주택보급률**: 다가구주택을 구분 거처 수로 산정
- **(종전)주택보급률**: 다가구주택을 1호로 산정

# 0002: 불용액 연구 (중앙정부)

[← 메인으로 돌아가기](../README.md)

## 개요

중앙정부 예산의 **불용액**(미집행 예산)을 분석하는 프로젝트입니다.

### 연구 질문

1. 불용액이 정권 초기에 더 많은가?
2. 국회에서 증액된 예산(쪽지예산)은 비효율적으로 집행되는가?
3. 연말에 집중해서 집행되는 예산은 비효율적인가?
4. 연초에 집행되지 않는 예산은 비효율적인가?

### 분석 기간

- 2007년 ~ 2018년 (이명박 정부, 박근혜 정부)

## 코드 구조

### 실행 순서

```
1. Extraction (데이터 수집)
   ├── 1. Final_extraction_longdata_002.sas  → longdata_002
   ├── 2. Final_extraction_longdata_004.sas  → longdata_004
   └── 3. Final_extraction_longdata_GDP.sas  → longdata_GDP

2. Preparation (전처리)
   └── 4. Final_Preparation.sas              → M01, M02

3. Statistics (분석)
   └── 5. Fianl_Satistics.sas                → 회귀분석 결과
```

### 파일 설명

| 파일명 | 역할 |
|-------|------|
| `1. Final_extraction_longdata_002.sas` | 열린재정 API에서 예산편성현황 추출 (정부안 vs 국회확정안) |
| `2. Final_extraction_longdata_004.sas` | 열린재정 API에서 결산현황 추출 (지출목별 상세) |
| `3. Final_extraction_longdata_GDP.sas` | e-나라지표 API에서 GDP 성장률 추출 |
| `4. Final_Preparation.sas` | 데이터 병합, 변수 생성 (불용액비율, 국회증감비율 등) |
| `5. Fianl_Satistics.sas` | 기초통계량, 상관분석, 회귀분석 |
| `40. Final_Preparation(modify).sas` | 수정 버전 - 투자/융자 계정 추가 (논문 심사 후) |
| `50. Fianl_Satistics(modify).sas` | 수정 버전 - 계정별 회귀분석 추가 |
| `Variations with Labels.csv` | 변수 정의 및 레이블 |

> **참고**: `(폐기)` 표시된 파일은 개발 과정의 기록용이며 실행 불필요

## 분석 방법

### 기초 통계

- 연도별, 지출목별, 회계별, 소관별 불용액 현황
- 변수 간 상관관계 분석

### 회귀분석 모델

| 모델 | 종속변수 | 독립변수 | 연구 질문 |
|-----|---------|---------|----------|
| reg01 | v21 (불용액비율) | x3, x31, x4 (정권 연차) | 정권 초기 불용액 |
| reg02 | v21 (불용액비율) | v7 (국회증감비율) | 국회 증액 효과 |
| reg03 | v21 (불용액비율) | v7, x5 (증가 더미) | 국회 증액 방향별 효과 |
| reg04 | v21 (불용액비율) | 연말 집행 더미 | 연말 집중 집행 |
| reg05 | v21 (불용액비율) | 연초 집행 더미 | 연초 미집행 |

### 통계 기법

- `PROC MEANS`: 기초통계량
- `PROC CORR`: 상관분석
- `PROC TTEST`: 그룹 간 평균 비교
- `PROC GLMSELECT`: 다중회귀분석 (더미변수 포함)
- `PROC SGPLOT`: 시각화

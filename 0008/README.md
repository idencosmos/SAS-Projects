# 0008: 불용액 연구 (지방재정)

[← 메인으로 돌아가기](../README.md)

## 개요

지방자치단체의 예산 집행률과 정치적 요인 간의 관계를 분석하는 프로젝트입니다.

### 연구 질문

**지방자치단체장의 정당이 중앙정부(여당)와 일치하면 예산집행률이 높아지는가?**

### 분석 기간

- 2008년 ~ 2017년 (기초지방자치단체)

## 코드 구조

### 실행 순서

```
1. Extraction (데이터 수집)
   ├── ext01.sas  → API 데이터 (table001-003, 008-012)
   ├── ext02.sas  → Excel 세입목별 데이터 (table004)
   ├── ext03.sas  → 시도지사 선거 데이터 (table005)
   └── ext04.sas  → 시군구의장 선거 데이터 (table006)

2. Preparation (전처리)
   ├── pre01.sas  → 변수 생성 (var001-004)
   ├── pre02.sas  → 선거 데이터 병합 (var005-008)
   └── pre03.sas  → 최종 분석 데이터 (var009)

3. Statistics (분석)
   ├── stat01(pre).sas  → 기초통계, 시각화
   ├── stat02.sas       → 기초통계량
   └── stat03.sas       → 회귀분석
```

## 분석 방법

### 기초 통계

- 연도별 집행률 추이
- 지역별 집행률 비교
- 이월액/불용액 현황

### 회귀분석 모델

```
ratio_remainder = β0 + β1*comp1 + β2*comp2 + β3*var102
                + β4*var37 + β5*var101 + 통제변수 + ε
```

| 분석 | 설명 |
|-----|------|
| 모델 1 | 기본 모델 (전체 샘플) |
| 모델 2 | 비선거 연도만 (`var103=0`) |
| 모델 3 | 재정자주도 교차항 (`comp1*rate4`) |
| 모델 4 | 여당 일치만 |
| 모델 5 | 광역단체장 일치만 |

### 시각화

- `PROC SGPLOT`: 연도별/지역별 시계열 그래프
- 집행률, 이월액, 불용액 추이

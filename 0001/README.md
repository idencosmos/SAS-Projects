# 0001: PM10 미세먼지 분석

[← 메인으로 돌아가기](../README.md)

## 개요

환경부 환경통계포털 API를 활용하여 **PM10 미세먼지** 데이터를 수집하고, 시도별/연도별 추이를 분석하는 프로젝트입니다.

### 분석 내용

- 1995년~2015년 연도별 PM10 시도별 미세먼지 추이
- 2001년~2017년 월별 PM10 시도별 미세먼지 추이
- 시계열 그래프를 통한 시각화

## 매크로 설명

### %env 매크로

API에서 XML 데이터를 가져와 SAS 테이블로 변환하는 범용 매크로입니다.

```sas
%env(data=데이터셋명, url=API_URL);
```

**파라미터**:
- `data`: 생성할 SAS 데이터셋 이름
- `url`: 환경통계포털 API URL

**처리 과정**:
1. `PROC HTTP`로 API 호출
2. XML 응답을 `XMLV2` 엔진으로 파싱
3. XML 맵 파일 수정 (LENGTH 조정)
4. 데이터와 날짜 테이블 조인

1. **연도별 시도별 PM10 추이** (1995-2015)

3. **월별 시도별 PM10 추이** (2001-2017)
   - X축: 월, Y축: PM10 농도
   - 시도별 선 그래프

4. **월별 전국 총계 PM10 추이**
   - 전국 합계 기준 시계열

## 실행 방법

### 1. 환경 설정

```sas
/* 경로를 본인 환경에 맞게 수정 */
%let lib=xml;
%let dir=C:\Xml\;
libname &lib "&dir";
```

### 2. 매크로 파일 경로 설정

```sas
/* env_macro.sas 파일의 전체 경로 지정 필요 */
%include 'C:\경로\env_macro.sas';
```

### 3. 실행

1. `env_xml.sas` 파일 열기
2. 경로 및 API 키 수정
3. 전체 실행

### 4. 주의사항

- **API 키 필요**: 환경통계포털에서 API 키 발급 필요
- **네트워크 연결**: API 호출을 위한 인터넷 연결 필요
- **매크로 경로**: `%include` 문에서 `env_macro.sas`의 절대 경로 지정 필요

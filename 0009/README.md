## 개요

중앙정부 예산의 **추경(추가경정예산)** 반영 여부가 불용액에 미치는 영향을 분석하는 프로젝트입니다.

### 연구 질문

**추경 예산이 반영된 단위사업은 불용액이 더 많은가?**

- 추경 반영 여부 (v8)와 불용액 비율의 관계
- 추경 예산변화율 (v7)과 불용액 비율의 관계
- 국회심의과정 예산변화 (v4)와의 교차효과

### 분석 기간

- 2007년 ~ 2019년

## 데이터

### 데이터 소스

| 데이터 | 출처 | API | 기간 |
|-------|------|-----|------|
| 세출 세목 예산편성현황 (추경포함) | 열린재정 | `ExpenditureBudgetAdd2` | 2007-2019 |
| 세출/지출 결산현황 | 열린재정 | `ExpendituresSettlement` | 2007-2017 |
| 세출 세부사업 예산편성현황(총액) | 열린재정 | `ExpenditureBudgetInit1` | 2007-2019 |

### 예산 흐름

```
금년도조정원화금액 (m4)
        │
        ├── + 국회심의 (v2)
        ▼
금년도확정조정원화금액 (m5) = 금년도예산안
        │
        ├── + 추경심의 (v6)
        ▼
추경국회확정 (m3) = 세출예산액/당초지출계획액
        │
        ├── + 예비비, 이용, 전용, 이체
        ▼
세출예산현액/지출계획현액
        │
        ├── - 지출, 이월
        ▼
불용액
```

### 생성되는 데이터셋

| 데이터셋 | 설명 |
|---------|------|
| `longdata_001` | 세출 세목 예산편성현황 (추경포함) |
| `longdata_002` | 세출/지출 결산현황 |
| `longdata_003` | 세부사업 예산편성현황(총액) |
| `var001` ~ `var006` | 변수 생성 중간 테이블 |
| `final` | 최종 분석용 데이터셋 |

## 코드 구조

### 실행 순서

```
1. Extraction (데이터 수집)
   ├── 10. Final_extraction_longdata_001.sas  → longdata_001 (추경포함 예산)
   ├── 11. Final_extraction_longdata_002.sas  → longdata_002 (결산현황)
   └── 12. Final_extraction_longdata_003.sas  → longdata_003 (예산편성)

2. Preparation (전처리)
   ├── 20. pre.sas  → var001, var002 (기본 변수 생성)
   ├── 21. pre.sas  → var003, var004 (추가 변수)
   └── 22. pre.sas  → var005, var006 (최종 병합)

3. Statistics (분석)
   └── 30. stat.sas  → 회귀분석 결과
```

### 파일 설명

| 파일명 | 역할 |
|-------|------|
| `10. Final_extraction_longdata_001.sas` | 추경 포함 세출 세목 예산편성현황 추출 |
| `11. Final_extraction_longdata_002.sas` | 결산현황 추출 (불용액 포함) |
| `12. Final_extraction_longdata_003.sas` | 예산편성현황(총액) 추출 |
| `20. pre.sas` | 단위사업 기준 집계, 지출목별 비율 계산 |
| `21. pre.sas` | 전년도 데이터 연결, 증가율 계산 |
| `22. pre.sas` | 추경 변수와 결산 변수 병합 |
| `30. stat.sas` | 회귀분석 (추경 효과) |
| `Variations with Labels.xlsx` | 변수 정의 및 레이블 |

## 분석 방법

### 회귀분석 모델

```
v1 (불용액비율) = β0 + β1*v8 (추경반영) + β2*c4 + β3*c5 + β4*c7
                + β5*cr11...cr17 + fscl + OFFC_NM + FSCL_YY + ε
```

| 모델 | 독립변수 | 설명 |
|-----|---------|------|
| 모델 1 | v8 | 추경 반영 여부 |
| 모델 2 | v7 | 추경 예산변화율 |
| 모델 3 | v7 (v8=1만) | 추경 반영된 것만 |
| 모델 4 | v8, v4, v8*v4 | 국회심의 교차효과 |
| 모델 5 | v7, v4, v7*v4 | 국회심의 교차효과 |
| 모델 6 | v7, v4, v7*v4 (v8=1만) | 추경 반영된 것만 |

### 통계 기법

- `PROC GLMSELECT`: 다중회귀분석 (더미변수 포함)
